# Omni-Osint---herramienta-de-osint-python-webview-


## (version beta)

> [!NOTE]
> - ( 🌐 )    busqueda por ip
> - ( 📞 )    busqueda por numero de telefono
> - ( 🤖 )    busqueda por id de discord
> - ( 🧊 )    busqueda por id de roblox
> - ( ⚙️ )    informacion de un servidor de discord 
> - ( 📧 )    informacion de un email (no tiene api key por lo tanto no funcionara)
> - (  𝐆  )   google dork (**redes sociales**,**index off**,**base de datos (sql, csv)**,**documentos (pdf, excel)**,**env keys y contraseñas**)
> - (  ♪  )   informacion de un usuario de tiktok
> - (  📂 )   buscar en la base de datos
> - (  🧾 )   lenguajes : **español, ingles, ruso, arabe**
> - (  ♻️ )   ver historial de busqueda y borrarlo


cosas que se añadiran proximamente :

- grafica de estadisticas
- exif data y mas opciones de osint y utilidades...
- orden de botones custom






## instalacion  

- 1. clonar               →  `git clone https://github.com/Valengamerr/Omni-Osint---herramienta-de-osint-python-webview-.git`
  2. ir a carpeta         →  `cd Omni-Osint---herramienta-de-osint-python-webview-`
- 3. descomprimir el zip
- 4. ir a carpeta x2      →  `cd omni`
- 5. ejecutar             →  `python main.py`
